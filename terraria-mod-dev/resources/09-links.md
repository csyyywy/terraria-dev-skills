# 09. 参考资料与链接

## 官方（首选）

- **API 文档（类列表入口）**：https://docs.tmodloader.net/docs/stable/annotated.html
- **官方 Wiki（含中文页）**：https://github.com/tModLoader/tModLoader/wiki
- tModLoader GitHub：https://github.com/tModLoader/tModLoader
- 发布（Workshop）文档：https://github.com/tModLoader/tModLoader/wiki/Workshop
- ExampleMod 示例工程（1.4.4 分支）：https://github.com/tModLoader/tModLoader/tree/1.4.4/ExampleMod
- tModLoader.app：https://tmodloader.app

> 完整的官方页索引与提取要点见 `10-official-reference.md`（先读它再点链接）。

## 社区

- Terraria 官方论坛 Modding 区：https://forums.terraria.org/index.php?forums/modding.79/
- tModLoader Discord（开发问答）：wiki 首页有邀请链接
- Steam 讨论区：https://steamcommunity.com/app/1281930/discussions/

## 第三方/进阶

- DeepWiki 的 tModLoader 概览（结构/构建/示例导读）：https://deepwiki.com/tModLoader/tModLoader
- CalamityTeam/tml-build：社区 MSBuild SDK 工具链：https://github.com/CalamityTeam/tml-build
- 常用库：StructureHelper、SubworldLibrary 等（Steam 工坊搜索）。
- 大型开源模组参考：CalamityMod、TerrariaOverhaul（GitHub）。

## 本机工具速查

| 工具 | 位置 |
|---|---|
| tML 安装 | `<STEAM_LIB>\steamapps\common\tModLoader` |
| tML 用户数据 | `%USERPROFILE%\Documents\My Games\Terraria\tModLoader` |
| tML 日志 | `<STEAM_LIB>\steamapps\common\tModLoader\tModLoader-Logs`（本机 Logs.lnk 指向处） |
| .NET SDK | `%USERPROFILE%\.dotnet\dotnet.exe`（8.0.423） |
| 工作区 | `<WORKSPACE>\MyMod` |
